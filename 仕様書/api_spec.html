外部システム連携 API 仕様書

電子カルテ端末、受付案内サイネージ、院内かわら版システム、外部グループウェア、Googleカレンダー等と予定データを連携するためのAPI仕様書です。

1. 通信規約・共通仕様

ベースURLhttp://[サーバーホスト]/yotei/api/
通信プロトコルHTTP / HTTPS (GET メソッド中心)
データ形式JSON (UTF-8, application/json; charset=utf-8) / iCalendar (RFC 5545)
CORS対応Access-Control-Allow-Origin: *（院内別システムからのAjax通信可能）
インタラクティブコンソールhttp://[サーバーホスト]/yotei/api/index.php

1.1 統一JSONレスポンス形式

すべてのJSON APIは以下のエンベロープ形式で返却されます。

{
    "status": "success",          // 処理結果 ("success" または "error")
    "code": 200,                  // HTTPステータスコード
    "timestamp": "2026-10-08T23:13:17+09:00", // 応答日時 (ISO 8601)
    "count": 5,                   // 返却データ件数
    "meta": { ... },              // 検索条件等の付帯情報 (任意)
    "data": [ ... ]               // 実際のデータ配列またはオブジェクト
}

2. 本日サマリー API

リクエストパラメータ

パラメータ名型必須デフォルト説明
datestring任意today対象日 (YYYY-MM-DD, today, tomorrow)

3. 予定一覧・期間検索 API

GET /api/events.php

用途: 電子カルテや院内グループウェア、週間カレンダー画面向けの柔軟な予定検索API。

リクエストパラメータ

パラメータ名型必須デフォルト説明
start_datestring任意当月初日期間開始日 (YYYY-MM-DD)
end_datestring任意翌月末日期間終了日 (YYYY-MM-DD)
datestring任意なし単一日指定 (指定時はstart/endを上書き)
doctor_idinteger任意なし特定医師IDで絞り込み
department_idinteger任意なし部門IDで絞り込み
event_typestring任意なし種別 (absence, clinic, meeting, business_trip)
expand_periodinteger任意01 指定時、複数日にまたがる期間予定を日別に分割展開して返却

4. マスタ・全体会 API

4.1 医師マスタ API (GET /api/doctors.php)

有効な医師一覧（ID、氏名、略称、役職、所属部門、カラーコード）を返却。

4.2 部門マスタ API (GET /api/departments.php)

部門一覧（ID、コード、名称、カラーコード）を返却。

4.3 小野会全体会日程 API (GET /api/meetings.php)

全体会の開催予定一覧。パラメータ: year (年数値), month (月数値)。

5. 連絡・申し送りメモ取得 API

GET /api/memo.php

用途: 医師予定表の最上部に常時掲載される自由記述メモ（診察予定の補足、休診振替、全体会連絡など）を取得するAPI。受付サイネージ、電光掲示板、院内グループウェア等の連携に適しています。

リクエストパラメータ

パラメータ名型必須デフォルト説明
formatstring任意jsonレスポンス形式。json または plain（text）。plain 指定時はメモ本文のみを Content-Type: text/plain で返却。
triminteger任意1空行の除外と行前後の余白トリム。1（有効）または 0（無効・元フォーマットを維持）。

6. iCalendar (.ics) カレンダー購読フィード

iCal /api/feed.php

カレンダー自動同期: Googleカレンダー、Outlook、iPhone、Androidのカレンダーアプリに本URLを「Webカレンダー購読」として登録するだけで、医師予定が端末のカレンダーに自動同期されます。

  • URL例: http://[サーバーホスト]/yotei/api/feed.php
  • 特定医師のみ購読: http://[サーバーホスト]/yotei/api/feed.php?doctor_id=2
  • 規格: RFC 5545 iCalendar (終日予定・時間指定予定・全体会を網羅)

7. クライアント実装サンプルコード

JavaScript (Fetch API)

// 今日の休診医師を取得して画面に表示する例
fetch('http://[サーバーホスト]/yotei/api/today.php')
    .then(response => response.json())
    .then(res => {
        if (res.status === 'success') {
            console.log('本日の休診人数:', res.data.summary.absent_count);
            res.data.absent_doctors.forEach(doc => {
                console.log(`🔴 [${doc.department_name}] ${doc.doctor_name}: ${doc.title} (${doc.time})`);
            });
        }
    })
    .catch(error => console.error('通信エラー:', error));

Python

import requests

url = "http://[サーバーホスト]/yotei/api/events.php"
params = {
    "start_date": "2026-10-01",
    "end_date": "2026-10-31",
    "event_type": "absence"
}

res = requests.get(url, params=params)
data = res.json()

for event in data["data"]:
    print(f"{event['start_date']}: {event['doctor']['name']} - {event['title']}")

8. ステータスコード一覧

コード意味説明
200 OK成功リクエストが正常に処理され、データが返却された。
400 Bad Requestリクエスト不正パラメータの日付フォーマットや指定形式が不正。
404 Not Found見つからない指定されたエンドポイントまたはデータが存在しない。
500 Server Error内部エラーデータベース接続エラー等のサーバー内部例外。
