PROGRAM SPECIFICATION

医師予定表管理システム 仕様書

システム名称: 医療法人小野会 医師予定表管理システム (yotei) • バージョン: v2.0 • 発行日: 2026年10月8日

1. システム概要・目的

本システムは、医療法人小野会に所属する医師の日常的な診察予定、休診・不在、出張・学会、および定期的な「小野会全体会」の日程を一元的に管理し、院内スタッフおよび関連業務システム（電子カルテ、受付サイネージ、院内かわら版等）へリアルタイムに情報共有することを目的としたWebシステムです。

v2.0 改定の主要ポイント:
1. かわら版システムとの完全統合認証（ワンタップログイン ＆ スマホ端末180日自動固定）
2. Googleカレンダー風の「週またぎ帯（マルチデイバー）」カレンダーの導入
3. 過去予定の視認性改善（濃色スレートグレー ＆ ⏳過去バッジの明示）
4. マスター管理の安全な管理者パスワード認証化（ソース内固定書ききりの完全撤廃）

2. 動作環境・アーキテクチャ

2.1 サーバー・実行環境

WebサーバーApache 2.4 (Win64)
言語・ランタイムPHP 8.5+ (PDO PostgreSQL 拡張)
データベースPostgreSQL 15 (UTF-8)
クライアント推奨環境Google Chrome, Safari, Microsoft Edge, iPad Safari (最新版)

2.2 データベース連携構成

本システムは単一のPostgreSQLインスタンス上で、以下の2つのデータベースと連携します。

yotei 予定表管理データベース（本体）
医師予定データ (events)、医師マスタ (doctors)、部門マスタ (departments)、小野会全体会 (all_meetings)、システム設定 (settings) を管理。
kawara 院内かわら版システム 統合マスターデータベース
全職員スタッフマスタ (staff) を参照。かわら版認証（PINコード・端末固定Cookie・管理者フラグ is_admin）およびイベント連携を担う。

3. 認証・端末固定仕様

院内かわら版システムと完全に同一のログイン画面・認証方式（LIB/auth_helper.php）を共有しています。

  • ワンタップログイン: スタッフ一覧から自分の名前（写真アイコン付き）をタップするだけで即座にログイン。
  • 3×4 テンキー暗証番号（PINコード）認証: 暗証番号が設定されている医師・役職者・管理者は、タッチしやすいモーダルテンキーでPIN（4〜7桁）を入力して認証。
  • スマホ・ブラウザ端末自動固定（Remember Device）: 初回ログイン時に安全な署名付きCookie（kawara_device_token）を発行。以降180日間、ログイン画面を完全にスキップしてポータルへ自動遷移。
  • マルチタブ独立セッション（session_tab.php）: ブラウザの別タブで異なるスタッフとしてログインしてもセッションが混ざらないよう、URLパラメータ tab_id と sessionStorage を連動させてタブごとに独立したセッション状態を維持。

5. 各画面詳細仕様

5.1 ポータル・エントリ画面 (index.php)

当該システムのエントリ画面。ログイン中のスタッフ名を表示し、各主要機能への直感的なナビゲーションを提供。

  • 主要機能カード: 1) 医師予定表一覧（yotei_list.php）、2) 小野会カレンダー（calendar.php）、3) 新規予定登録（input.php）、4) マスター管理（master/index.php ※管理者認証）、5) 外部連携API（api/index.php）、6) 院内かわら版（/kawara/index.php）。
  • ダッシュボードウィジェット: 今後14日間の直近予定サマリー、および当月の小野会全体会案内（開催予定/開催済みステータス）を表示。

5.2 医師予定表一覧 (yotei_list.php)

医師の予定を時系列に一覧表示する基本画面。印刷用スタイル（@media print）に最適化。

  • 過去予定の視認性向上: 従来の opacity: 0.4 によるかすれ文字を撤廃。背景 #f8fafc に濃いスレートグレー（#334155）のテキストを採用し、可読性と印刷品質を担保。
  • ⏳ 過去バッジ: 昨日以前の過去の予定行には、予定内容セルおよび操作セルに ⏳ 過去 バッジを明示し、直感的に判別可能。
  • 操作機能: 公開／非公開のワンタップ切替、予定取消、取消予定の復活（履歴管理テーブル event_history に完全記録）。

5.3 小野会カレンダー (calendar.php)

Googleカレンダーに匹敵するリッチな月間カレンダー。CSS Gridによる週単位スロットシステムを搭載。

  • 週またぎ帯（マルチデイバー）表示: 複数日にまたがる予定（出張・休診・リフォーム等）は該当列を連続横断するカラーバーとして描画。土曜〜日曜の週またぎ時は右端 ▶ および翌週左端 ◀ の継続インジケーター付きで自然に折り返し。
  • リッチホバーツールチップ: PCではバーにマウスオーバーすると、医師フルネーム・時間帯・タイトル・備考・状態カードが即座にポップアップ。
  • 1ヶ月表示 ⇔ 3ヶ月連続表示切替: 上部トグルボタンでワイドな1ヶ月表示と、連続3ヶ月縦積み表示をワンタップ切替。
  • +他○件 ＆ 当日全予定モーダル: 1日に予定が集中した場合（1ヶ月表示は4件目以降）、下部に「+他○件」を表示。クリックで当日の全予定一覧モーダルを展開。

5.4 新規予定登録 (input.php)

予定の新規作成画面。スマートフォンでもスクロール不要で素早く入力できるよう縦方向を圧縮。

  • 期間指定時の終日固定仕様: 日付パターンで「期間」を選択した場合、時間パターンは「終日」に自動固定（開始・終了時間入力欄を自然に非活性化）。
  • 動的戻り先: パラメータ return_to（list / calendar / index）に応じて、キャンセル時および登録完了時の遷移先を自動連動。

5.5 マスター管理 (master/index.php)

医師マスタ、部門マスタ、全体会日程、特記事項の管理機能。

  • 安全な管理者暗証番号認証 (LIB/master_auth.php): ソース内の固定書ききりを全廃。かわら版スタッフマスター上の管理者（is_admin = true）の暗証番号（PINコード）で照合して認証。

7. セキュリティ・保守方針

  • パスワード直書きの完全排除: システム内の全スクリプトからハードコードパスワードを撤廃。管理権限の照合はデータベースの正規アカウントを介して実施。
  • SQLインジェクション対策: すべてのDBクエリにPDOプリペアドステートメントを採用。
  • XSS（クロスサイトスクリプティング）対策: 画面出力時に htmlspecialchars() によるサニタイズを徹底。
  • 操作履歴の保存: 予定の取消・復活・公開切替は event_history テーブルに変更内容・操作日時・操作者を記録。
