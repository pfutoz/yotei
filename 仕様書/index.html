外部連携 API 仕様書

システム基本要目

システム名称 医療法人小野会 医師予定表管理システム（システムコード: yotei）
システム目的 医師の診察日・休診・不在・学会出張、および小野会全体会の日程を一元管理し、院内スタッフおよび関連システムへリアルタイムに共有する。
サーバー環境 Apache 2.4 / PHP 8.5 / PostgreSQL 15 / Windows Server
連携データベース yotei（予定表本体DB）
kawara（院内かわら版・スタッフ統合マスターDB）
認証基盤 かわら版スタッフ認証統合（スタッフ選択＋暗証番号＋180日端末記憶Cookie）
システムエントリURL http://[サーバーホスト]/yotei/index.php
APIインタラクティブコンソール http://[サーバーホスト]/yotei/api/index.php
